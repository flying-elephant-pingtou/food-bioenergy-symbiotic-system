# Food-Bioenergy Symbiotic System (FBSS)
FBSS Research Data and Code Repository

This repository contains all MATLAB code used in the study titled "Region-tailored food-bioenergy symbiotic systems unlock appreciable climate benefits in China". 

I'm glad to be contacted xingjh21@mails.jlu.edu.cn

├── data/                  # Input data (biowaste availability, demand, technology parameters)
├── code/                  # Model and optimization scripts
│   ├── main/              # Main optimization routines
│   ├── objective/         # GHG and economic objective functions
│   ├── constraints/       # Supply chain and surplus constraints
│   └── utils/             # Supporting functions
├── results/               # Model outputs and processed results
├── figures/               # Scripts for reproducing figures in the manuscript
└── README.md              # This file
